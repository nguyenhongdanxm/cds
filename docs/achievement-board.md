# Bảng thành tích

Entry: `hoclieu_thanhtich.php`, in Tiện ích → Công cụ.

Permissions automatically follow PCCM: the published assignment snapshot takes priority; otherwise the current working version is used, including version-owned manual assignments and GDĐP range teachers. Link each account to its stable CSDL teacher ID/code in Tài khoản và quyền. Editable display names never grant access; ambiguous or invalid IDs fail closed. An assigned teacher can enter, revise and delete points only for assigned class/subject pairs in the current academic year. Explicit feature overrides still cap access; viewers stay read-only. Assignment changes revoke former rights on the next request. Administrators have full access and can inspect the read-only assignment/account mapping in the tool. Legacy manual grants apply only when no PCCM source exists.

Tổng hợp lớp lists all PCCM subjects and existing board subjects for the selected class, per-student subject totals, reward/penalty/net totals and ranks. Filters support week, month and custom dates, with CSV export. A teacher assigned to any subject in that class may read this aggregate table, but cannot read other subjects’ individual event histories or notes.

Each academic year / class / subject has independent criteria and an append-only event ledger in school-local `data/achievement_boards/<board-hash>.json` files, with grants in `data/achievement_board.json`. Award snapshots retain student/criterion labels and actor/time. Undo marks an event void without erasing it. Editing preserves the old event and appends a replacement; both actions retain actor/time history. Atomic JSON updates and request IDs avoid lost updates and duplicate award retries. Reports aggregate the selected week, month or custom range; the latest 200 history events are shown while totals include the complete range. CSV exports use UTF-8 BOM and spreadsheet-formula protection.

No student information is sent to an external service. Student mascots are original CSS artwork; sound is optional procedural Web Audio after user interaction and motion respects reduced-motion preferences.

Cover: `assets/game-covers/illustrated-v3/achievement.webp`, 720×405, generated with the built-in image tool. Prompt: original friendly classroom mascots celebrating with a golden trophy, stars, badges and plus-point tokens; pastel lavender/turquoise/gold; large Vietnamese title “BẢNG THÀNH TÍCH”, no brand characters, no logos or other text.

PCCM diagnostics: Phân quyền shows source row counts, matched teachers, linked accounts, per-row rejection reasons, ignored rows and account link diagnostics. Published versus working-version changes are flagged, never silently merged into authority. Zero weekly periods no longer remove an annual teaching assignment. Class case/whitespace differences are normalized only when there is exactly one master class match. Missing, inactive or ambiguous teacher/class identities remain blocked with an explanation.

The personal creative studio offers Candy, Space and Garden themes and a motion switch, saved in the browser. Eight original 3D companions and four icons are in `assets/achievement/` (built-in image generation; prompt: twelve-cell transparent 4×3 clay-art atlas, eight original expressive colorful school creatures and trophy/star/target/books, no lettering or brand characters). Generated atlas was sliced into WebP assets for small downloads. Teachers may add up to 20 custom companions per class–subject, from public HTTPS image URLs or PNG/JPG/WebP uploads (client downsizing, server MIME/dimensions/350 KB validation). Choose students before applying a companion; these shared choices persist in that board and obey PCCM edit scope. Viewers can change their personal theme but cannot add, remove or assign companions. Point ledgers remain unchanged by artwork operations. Reduced-motion settings are respected, and external images use no-referrer requests with an in-page fallback on load errors.

Teacher identity accepts equivalent trailing disambiguators `Nguyễn Thị Hoa V` / `Nguyễn Thị Hoa (v)` and `T` / `(t)`, preserving the suffix. Missing suffixes and canonical duplicate names never guess a teacher; explicit IDs/codes still take priority. The administrator account save uses the same canonical form.

Accessory animal collection v2: 48 additional original 3D animals, each with a distinct prop/outfit, in three 4×4 transparent WebP atlases `assets/achievement/animals-v2-{1,2,3}.webp`; existing eight companions remain available (56 total). Generated using the built-in image tool with prompts requesting equal-cell, fully padded, expressive colorful clay animals with flags, headbands, hats, scarves, backpacks and other accessories, no branding/text. Server allocation sorts immutable student IDs and reserves explicit choices, so a class of up to 56 gets distinct defaults, unaffected by score/rank ordering. Larger classes report unavoidable repeats. The creative studio shows usage counts and search, warns before explicit duplicate choices, and offers a PCCM-scoped redistribution button that clears per-board selections and changes only the art seed, preserving all point history.
